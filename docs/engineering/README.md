# Engineering Standards

These documents contain recurring mandatory engineering practices. They are
not historical decisions like ADRs; they describe the current quality bar for
the repository. This baseline targets Java 21+ and is Spring-friendly. An
adopting project must explicitly adapt framework, build, persistence, and test
commands when its active ADRs select different technologies.
